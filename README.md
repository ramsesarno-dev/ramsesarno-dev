## Featured Projects

### [NexoFEL RD](https://github.com/ramsesarno-dev/NexoFEL-RD)

Academic web application for invoicing and basic inventory management, built with **C#, .NET 8, ASP.NET Core MVC, Entity Framework Core, and SQL Server**.

[![Build and tests](https://github.com/ramsesarno-dev/NexoFEL-RD/actions/workflows/build.yml/badge.svg?branch=main)](https://github.com/ramsesarno-dev/NexoFEL-RD/actions/workflows/build.yml)

- Prototype issuance flows for E31, E32, and E45 documents, with E33 debit notes and E34 credit notes linked to the original document.
- Customer and product management, e-NCF ranges, inventory movements, dashboards, and reports.
- Role-based access using ASP.NET Core Identity and safeguards against duplicate invoice submissions.
- PDF documents with QR codes for authenticated internal consultation.
- **83 unit tests and 129 SQL Server integration tests**, with automated validation through GitHub Actions.

**Scope:** Academic prototype. It does not provide digital signing, submission to DGII, or official acceptance of electronic fiscal documents. Its internal QR codes are not official DGII validation codes.
